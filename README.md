# IAM Access Review & Suspicious Login Investigation Project Overview

A simulated Identity and Access Management (IAM) access review for a fictional company, using synthetic user, permission, and login data to identify users with, excessive permissions,
inactive accounts, shared/admin accounts, failed login spikes, successful logins after repeated failures, and users who may need MFA or access removal.

## Tools Used

- CSV files
- Python (pandas)
- SQL
- GitHub

## Data

All data in this project (`users.csv`, `access_permissions.csv`, `login_attempts.csv`) is synthetic and fictional. No real company, employee, or login data is used.
